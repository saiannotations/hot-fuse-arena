# Security Policy

Hot Fuse Arena is a small open-source party game. If you find a security issue
(especially anything around the WebSocket server, room codes, or the deploy
workflow), please report it responsibly:

- Open a **private** report via GitHub Security Advisories on this repo, or
- Email the maintainer instead of opening a public issue.

Please do not commit secrets, API tokens, or Cloudflare credentials anywhere
in this repository. Deployment uses GitHub Secrets only.
